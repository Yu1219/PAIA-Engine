# 優先度「高」の機能：実装と検証結果

更新版は `C:\Python\ProteinAnnotation\PAIA_Engine.bat` から起動できます。
実行ファイルは `dist-high-priority\PAIA_Engine\PAIA_Engine.exe` にあります。移動する場合は `_internal` を含め、PAIA_Engine フォルダー全体を移動してください。

## 実装した機能

- 用途別プリセット、入力プレビュー、重複・空欄の表示。
- ID対応付けの確認、複数候補の選択、種の表示。
- 局在・分類・数値・文字列を組み合わせる絞り込み、表示列の選択。
- タンパク質詳細、根拠・出典・取得日時、配列上の位置表示。
- GOの3分類、ドメイン／ファミリー、PTM位置・根拠、膜局在・細胞表面候補。
- 元データの行と値を保持する全件CSV、絞り込みCSV、根拠JSON。

## 検証

- 自動テスト：32件すべて成功。
- 実API：UniProt と InterPro から公開タンパク質5件を取得。6種類のID中5件が一致し、不正IDは未一致として扱いました。
- 重複ID・空欄IDを含む8行を、元の行数と値を保持して出力しました。
- 膜局在・受容体分類・分子量の複合条件でEGFRを抽出しました。
- 画面操作、CSVのダウンロード、実行ファイル版での44項目の処理を確認しました。

画面の入力方法で **Test dataset (offline)** を選ぶと、同梱した公開データで試せます。
実APIの検証記録は `live_validation.json`、出力例は `annotated_test_proteins.csv`、絞り込み例は `filtered_egfr.csv` です。

分類が空欄の場合は根拠のある注釈がないことを示します。PTM件数0は登録部位がないという意味です。細胞表面候補は局在・膜トポロジーからの候補判定です。
