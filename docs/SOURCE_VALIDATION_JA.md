# Python 3.14ソース版の検証結果

検証日：2026年10月8日。詳細説明書と補助機能の追加検証：2026年10月9日。

## 検証環境

- Windows x64
- 通常版CPython 3.14.8（Python公式のWindows配布を利用）
- アプリ専用の仮想環境 `.venv`
- ブラウザーによる画面操作：Chromium

使用バージョンは `requirements-windows-py314.lock` に固定しています。主な構成はStreamlit 1.65.0、pandas 2.3.3、NumPy 2.5.3、Plotly 6.9.0、aiohttp 3.14.4、openpyxl 3.1.5、xlrd 2.0.2です。

exeの検証時は子プロセスのPATHをWindowsのフォルダーだけにし、PYTHONPATHとPYTHONHOMEを除外、ユーザーサイトの利用も無効にしました。外部Pythonへ依存しない構成を確認するための条件です。**PythonをアンインストールしたPCや別PCでの検証ではありません。** 今回作成したexeからの新しいオンラインDB取得は未実施です。ソース版のオンライン確認は上の10月8日の記録を参照してください。

作成直後の`build_report.json`は実行確認を`false`と記録します。ビルド成功だけを動作確認の成功とせず、展開先での操作結果を別に記録してください。
