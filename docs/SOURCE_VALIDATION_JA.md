# Python 3.14ソース版の検証結果

検証日：2026年10月8日

## 検証環境

- Windows x64
- 通常版CPython 3.14.8（Python公式のWindows配布を利用）
- アプリ専用の仮想環境 `.venv`
- ブラウザーによる画面操作：Chromium

使用バージョンは `requirements-windows-py314.lock` に固定しています。主な構成はStreamlit 1.65.0、pandas 2.3.3、NumPy 2.5.3、Plotly 6.9.0、aiohttp 3.14.4、openpyxl 3.1.5、xlrd 2.0.2です。

## 確認できたこと

| 確認項目 | 結果 |

| 新規の専用環境作成とライブラリの自動インストール | 成功。システム全体のライブラリを変更せず、`.venv` に準備 |
| 配布用ZIPからの新規セットアップ | 別フォルダーに展開し、同梱の固定バージョン一覧でインストール成功 |

| ライブラリの依存関係確認 | `pip check` で問題なし |
| 既存の自動テスト | 32件すべて成功 |
| 起動ファイルからの2回目のセットアップ | パッケージ配布サイトへの接続を無効にした状態でも、準備済み環境を使用 |
| アプリの起動 | ローカルの操作画面が応答 |
| オフラインデータの実画面操作 | 入力確認、アノテーション、タンパク質詳細の切り替えが成功 |
