## Geminiによる検証設計

[実際のGemini会話](https://gemini.google.com/app/884d1c5f26ae8bab)。受信版1.1、開始コミット69cc3b8を返答。Notion/ソースの取得やテスト実行は行わず、渡した仕様本文だけから検証を設計したと明示。

| ID | 独立に提案された検証 | Codexの反映 |
|---|---|---|
| TC-DATA-01 | CSV/TSV/Excel、空行、重複、先頭ゼロ、既存列を含む入力とCSVの整合性 | test_desktop.pyに3形式とCP932・空行・列名衝突の確認を追加 |
| TC-OFFLINE-01 | 通信を使わずサンプル8行、6種のうち5種一致、絞り込み・詳細・保存を完遂 | オフライン解析・CSV・根拠の復元を自動確認。画面でも実行 |
| TC-STATE-01 | JSON保存、別起動で復元、破損JSON拒否、処理中の前結果保護 | 7種の破損、処理中の復元拒否、中止・通信失敗・再試行を追加 |
| TC-UI-RETRY-01 | 768px以下、キーボードのみの主要操作、入力・通信エラー後の復帰 | 実画面で確認し、結果をリリース検証に記録 |
| TC-DEPLOY-01 | Python未導入環境でZIP起動、旧UI、OS別ビルド、Gitタグ復元 | 展開先移動と実行確認、旧版タグ・ソースZIP・Git bundleを用意。クリーンな別PCは未実施 |

Geminiの案は仕様の正本ではありません。返答内の「空欄2行」は誤りのため、実データの「空欄1行・重複1行」に補正しました。またCSVと根拠JSONは別成果物で、CSVの各セルに根拠JSON全文を埋める意味ではありません。マシンのネットワーク設定を切断した試験と、コード上で通信を使わない経路の試験も区別します。

## モデルの使い分け

タスクの重さに応じて選択。Gemini Flashは仕様からの最大5件の検証項目作成。設計、データ保護、統合と実行確認はCodexが担当。保存・APIの重要レビューはClaudeの高性能モデルに絞って依頼し、全文書の繰り返し投入を避ける。モデルの助言と実際に再現した結果を区別する。
