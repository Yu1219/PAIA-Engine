# PAIA Workbench 2.0.1

日本語の新画面です。旧Streamlit版の解析処理を共用しています。アプリの利用にLLMやAPIキーは不要です。

## 配布版を起動

Windows x64用ZIPを**すべて展開**し、`PAIA_Workbench/PAIA_Workbench.exe`を起動してください。`_internal`を含むフォルダー全体を保管します。Pythonや追加ライブラリのインストール、管理者権限は不要です。Edge・Chromeなどのブラウザーが必要です。

空いているポートを自動で選び、このPCだけから接続できる操作画面を開きます。画面が開かないときは、起動用ウィンドウに表示された`http://127.0.0.1:番号`を開きます。同時に複数起動しても、それぞれ別の作業になります。

このWindows版はWindows x64向けです。「すべてのPCで同じ実行ファイルが動く」という意味ではありません。macOS・Linux・Windows ARMでは各OS/CPU用のビルドが必要です。macOS/Linuxの実機確認は未実施です。セキュリティソフトや組織の利用制限があるPCでは、そのPCでの確認が必要です。

Windows x64、macOS arm64（Apple Silicon）、Linux x64の配布物を作成しました。3つのOSのクラウド環境でも、展開後の実行ファイルによる読み込み・保存・復元・再起動が合格しています。確認環境はWindows、macOS26.7.2 arm64、Linux x64/glibc2.43です。古いOS、Intel Mac、Windows ARM、別のLinuxディストリビューションでの動作は未確認です。Mac/Linuxでは展開後の`PAIA_Workbench/PAIA_Workbench`を実行します。実行権限を保持できない展開ソフトを使った場合は、そのファイルに実行権限を設定します。

## 最初の操作

1. 「サンプル」→「サンプルを読み込む」を選びます。
2. 「アノテーションを実行」を押します。通信なしで8行・6種類のIDを解析し、5種類が一致します。重複は1行、空欄は1行です。
3. 結果の検索・局在・分類・数値条件で絞り込みます。見たい項目は「表示列を選ぶ」で追加できます。局在の分布は表示中のIDに連動します。
4. 各行の「詳細」で注釈、出典、取得日時、根拠を確認し、必要なら根拠JSONを保存します。
5. 「全行をCSV保存」で入力8行を保った結果を保存します。「表示中をCSV保存」は絞り込んだIDに対応する元の行だけを保存します。

## 自分のデータを調べる

直接入力は1行1ID。ファイルはCSV、TSV、XLSX、XLSに対応し、先頭行を列名として扱います。最大24MB・10,000行・250列です。CSVはUTF-8またはCP932に対応します。IDと元データを文字列として読み、先頭ゼロや文字列NA、空欄・重複を保ちます。Excelの表示書式そのもの、数式や図・複数シートは保存しません。先頭シートの値を読み込みます。

最新データを調べるときは取得元を「最新の公開データベース」に変えます。選択したIDをUniProt、必要に応じてアクセッションをInterProへ送信します。入力ファイル全体をクラウドへ保存する機能はありません。通信失敗時はエラーを確認して再実行できます。処理中や中止時は以前の結果を保持します。部分的な通信失敗は該当IDの状態に表示します。

生物種とID形式を確認してください。完全一致のアクセッションは他の生物種でも取得し、警告を表示します。遺伝子名・タンパク質名の検索は指定生物種で絞ります。複数候補があるIDは自動確定しません。詳細から意図した候補を選択し「この候補で確定」を押してください。アイソフォームは専用の確認が必要なため、標準配列と同一視しません。

CSVには元の列・行順を保って注釈を追加します。同じ名前の既存列がある場合、新たな注釈列に`_PAIA`を付けます。元のセルに数式の文字列がある場合、その文字列も保持します。表計算ソフトで開くときは外部由来の数式に注意し、文字列として読み込んでください。

## 作業を保存し、別PCで再開

上部の「プロジェクトを保存」は入力表、実行時の設定、結果、出典・根拠を1つのJSONへ保存します。別PCでも同じ版のアプリで「プロジェクトを開く」を選べます。復元とCSV保存には通信不要です。元の生データベース応答全体は含めず、表示・検証に必要な注釈と根拠を保持します。

**終了時に自動保存しません。** ブラウザーの再読み込みは起動中の結果を復元しますが、アプリ終了後の再開にはJSONが必要です。入力や設定を編集しただけでは前の結果は変わりません。表示・保存対象は最後に完了した解析です。プロジェクトには入力値が含まれるため、共有先は自身で確認してください。

終了ボタンから「プロジェクトを保存」を選び、保存先でJSONを確認してから「終了する」を押します。保存をキャンセルした場合も、アプリはそのまま残ります。起動用ウィンドウを閉じても終了できます。

## 注釈の解釈

空欄や「登録根拠なし」は、その性質が生物学的に存在しないことの証明ではありません。理論等電点は配列からの計算、細胞表面候補は登録局在などからの候補判定です。サンプルは取得日が固定された保存済み公開データです。UniProtのレビュー済み表示は、すべての注釈が実験で確認された意味ではありません。

## 旧版へ戻す

旧Streamlit版の`app.py`、`launcher.py`と既存の配布物を残しています。旧版は従来の`PAIA_Engine_Source.bat`または既存の`PAIA_Engine.exe`から起動できます。新UIのプロジェクトJSONを旧UIへ読み込む機能はありません。新UIから全行CSVとJSONを保存してから戻してください。

コードの保存点は`baseline-before-v2-20261107`です。現在の作業を壊さず別フォルダーへ元版を取り出すには、リポジトリで次を実行します。

```powershell
git worktree add ../ProteinAnnotation-v1 baseline-before-v2-20261107
```

元のソースだけをZIPで取り出す場合：

```powershell
git archive --format=zip --output=../PAIA-v1-source.zip baseline-before-v2-20261107
```

## 開発と各OS用ビルド

Python 3.14の環境で新UI用依存だけを導入できます。新UIはStreamlit、Plotly、外部CDNを使用しません。

```powershell
python -m venv .venv-desktop
.venv-desktop/Scripts/python -m pip install -r requirements-desktop.txt -r requirements-build.txt
.venv-desktop/Scripts/python paia_desktop.py
.venv-desktop/Scripts/python build_workbench.py
```

macOS/LinuxではPythonのパスを`.venv-desktop/bin/python`に置き換えます。ビルドは必ず対象OSで実行します。配布物は`output/workbench/版-OS-CPU-日時/`に作成し、ファイル一覧、SHA256、開始コミット、ビルド環境を記録します。既存版を上書きしません。`--port 0`は空きポートの自動選択、`--no-browser`は画面の自動表示を省く開発用の指定です。
